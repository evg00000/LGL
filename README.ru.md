# LGL — Local Games Launcher

[English version](README.md)

Лёгкий лончер локальных игр с управлением геймпадом для **Windows XP** и новее.
По духу — как OPL на PS2 или Steam Big Picture, но это один нативный Win32-файл,
который спокойно работает на Pentium III.

## Возможности

- **Интерфейс под геймпад**: навигация, запуск, настройки и выключение ПК без клавиатуры.
- **Сканирование папок**: укажите папку с играми — каждая подпапка станет игрой.
  Главный `.exe` определяется сам (установщики, деинсталляторы, конфигураторы и redist пропускаются)
  и меняется в настройках игры.
- **Маппинг пада на клавиатуру и мышь** для старых игр, которые не знают про геймпады:
  стики как WASD, стрелки или мышь, слой-модификатор (зажатая LB даёт второй набор клавиш),
  сочетания вроде `Ctrl+1`, минимальное время удержания для игр, пропускающих короткие нажатия.
  Ввод отправляется только когда активно окно игры.
- **Редактор раскладки с пада**: любая кнопка назначается из экранной сетки или нажатием
  клавиши на настоящей клавиатуре. Правка общего профиля создаёт свою копию для этой игры.
- **Правильное слежение за игрой**: игры запускаются в Job Object, поэтому игры со своим
  лончером отслеживаются верно. Пока идёт игра, лончер скрыт, а после выхода возвращает
  разрешение экрана и забирает фокус.
- **Закрыть любую игру с пада**: удерживать Back + Start 1,5 с (повторно — принудительно).
- **Обложки** из папки `covers` или `folder.jpg` в папке игры, плюс скрипт загрузки с SteamGridDB.
- Избранное, недавние, время в игре, скрытые игры, сортировка, прыжки по первой букве.
- Пять цветовых тем, фоновые фото с настраиваемым затемнением, звуки навигации.
- Русский и английский интерфейс с переключением в меню.
- Автозапуск с Windows, перезагрузка и выключение из меню — ПК как приставка.

## Требования

- Windows XP SP2 или новее (32-битная сборка; работает и на Windows 11).
  Проверено на Pentium III 1 ГГц, 512 МБ ОЗУ.
- XInput-геймпад: Xbox 360 или совместимый (8BitDo, Logitech F310/F710 в режиме X, PowerA, PDP…).
- На Windows XP:
  - Xbox 360 Accessories Software 1.2 (драйвер контроллера Xbox 360);
  - DirectX 9.0c End-User Runtime (June 2010) — для `xinput1_3.dll`.
  - Сторонним XInput-падам может понадобиться [PadDriverFix](#paddriverfix), чтобы встал драйвер.

DirectInput-пады (DualShock, адаптеры PS2, обычные HID-пады) пока не поддерживаются.

## Быстрый старт

1. Скопируйте `LGL.exe` в любую папку и запустите. Рядом появятся `games.ini` и `profiles.ini`.
2. Откройте `games.ini` и укажите папку с играми:
   ```ini
   [launcher]
   scan=D:\Games
   ```
   Строк `scan=` может быть несколько.
3. Нажмите **F5** (или Start → Пересканировать игры). Каждая подпапка `D:\Games` — игра.
4. Для игры только с клавиатурой: **Y** → Профиль маппинга → *Шутер*, *Гонки* или *Стратегия*,
   либо **Y** → Раскладка кнопок, чтобы настроить свою.

## Управление

| Геймпад | Клавиатура | Действие |
|---|---|---|
| Крестовина / левый стик | Стрелки | Навигация |
| A | Enter | Запуск / выбор |
| B, Back | Backspace | Назад |
| X | Tab | Избранное |
| Y | Пробел | Настройки игры |
| LB / RB | PgUp / PgDn | Предыдущий / следующий раздел |
| LT / RT | Home / End, буквы | Прыжок по первой букве |
| Start | Esc | Меню лончера |
| Удерживать Back + Start (в игре) | — | Закрыть игру |
| — | F5 | Пересканировать игры |
| — | F11 | Полный экран |

## Файлы

Все файлы лежат рядом с `LGL.exe`.

| Файл / папка | Назначение |
|---|---|
| `games.ini` | Папки для сканирования, общие настройки, правки по играм. Правите вы. |
| `profiles.ini` | Общие профили маппинга (шутер, гонки, стратегия…). Правите вы. |
| `profiles_games.ini` | Свои раскладки игр. Пишет редактор раскладки. |
| `state.ini` | Избранное, время в игре, настройки из интерфейса. Пишет лончер. |
| `covers\` | Обложки по имени папки игры: `covers\Half-Life.jpg`. |
| `backgrounds\` | Фоновые картинки, выбираются в Start → Фон. |
| `sounds\` | Необязательные `move.wav`, `select.wav`, `back.wav`. |

### Правки для отдельной игры

Добавьте в `games.ini` секцию с именем папки игры
(`exe=` — относительно папки игры или полный путь):

```ini
[Heroes3]
name=Heroes of Might and Magic III
exe=Heroes3.exe
args=-nointro
genre=Стратегия
year=1999
profile=strategy
```

Игры вне scan-папок добавляются так же, с полным путём в `exe=`.

### Профили маппинга

Профили — обычные секции в `profiles.ini`; в созданном файле описаны все ключи.
Короткий пример (`^A` — кнопка A при зажатой кнопке слоя RB).
Комментарии в `.ini` — только целой строкой.

```ini
[shooter]
name=Шутер: WASD + мышь
lstick=wasd
rstick=mouse
mouse_speed=900
RT=MOUSE_LEFT
LT=MOUSE_RIGHT
A=SPACE
LB=WHEEL_UP
layer=RB
^A=F5
```

## Утилиты

### PadDriverFix

Ставит драйвер Xbox 360 на сторонние XInput-геймпады под Windows XP, где штатный драйвер
принимает только ID устройств Microsoft.

Утилита находит подключённые пады по классу интерфейса Xbox 360 (`USB\Class_FF&SubClass_5D&Prot_01`),
делает копию установленного `xusb21.inf` с их ID и устанавливает её. Файлов Microsoft
в комплекте нет: используется драйвер, уже установленный пакетом Xbox 360 Accessories 1.2.
Запускайте от администратора, с падом в режиме X-input, и согласитесь на предупреждение
о неподписанном драйвере.

### get-covers

Скрипт PowerShell для ПК с интернетом. Положите рядом `state.ini` и `games.ini`,
запустите `get-covers.bat` — он скачает вертикальные обложки с [SteamGridDB](https://www.steamgriddb.com)
(нужен бесплатный API-ключ) и уменьшит их в JPEG, чтобы медленный ПК быстро их декодировал.
Получившуюся папку `covers` скопируйте к лончеру.

Если игра сопоставилась неверно, добавьте в её секцию в `games.ini` строку `cover_search=` или `sgdb=<id>`.

## Сборка

Откройте `LGL.sln` в Visual Studio 2010 (подойдёт бесплатная Express) и соберите **Release | Win32**.
Файлы появятся в `bin\Release\`. CRT подключена статически: зависимостей нет, всё работает
на чистой Windows XP.

Каждый push дополнительно проверяется сборкой в GitHub Actions через Zig (Clang + MinGW).
Эта сборка нужна только для поиска ошибок; релизные бинарники собираются в Visual Studio 2010.

## Известные ограничения

- Только XInput-геймпады.
- До 512 игр и 32 профилей маппинга.
- Steam-игры с DRM могут не запуститься из exe или перезапуститься через Steam.
- Программы, которые эмулируют нажатия клавиш, прописываются в автозапуск и умеют выключать ПК,
  иногда вызывают срабатывание эвристики антивирусов. Исходники открыты — их можно проверить
  и собрать самостоятельно.
